# DS5020 Final Project — Iteration 2: Bayesian A/B Testing (Project 7)

Beta–Binomial model, Monte Carlo estimate of P(p_B > p_A | data), pooled two-proportion z-test,
a known-truth simulation, and the Cookie Cats dataset.

## Folder structure
```text
Bayesian_AB_Testing_Iteration2/
├── data/            cookie_cats.csv (not tracked by Git; see data/README_DATA.md)
├── docs/            main.tex, Iteration2_Report_Bayesian_AB_Testing.pdf, project plan (.xlsx), result CSVs
├── figures/         plots (generated by the scripts)
├── src/             common.py, simulation.py, real_data.py, hand_example.py, run_all.py
├── requirements.txt
└── README.md
```

## Run (from the project root folder)
```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1     macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt

python -m src.run_all --csv data/cookie_cats.csv   # simulation + real data
python -m src.simulation                            # known-truth simulation only
python -m src.real_data --csv data/cookie_cats.csv  # Cookie Cats only
python -m src.hand_example                          # small worked example
```
All random numbers use seed 0 (`np.random.default_rng(0)`), so every member gets identical output.
Scripts write to `figures/` and `docs/`; run them from the project root.

## Data
Download the Kaggle "Cookie Cats A/B testing" CSV and save it as `data/cookie_cats.csv`
(columns: `userid, version, sum_gamerounds, retention_1, retention_7`). Large raw files stay out of Git.
